# Issue Tracker Common Instructions

This Space coordinates work on the user's configured repository, not the repository that supplied the Kit. Read the authenticated Huabu root guide before Space operations and load focused live guidance only as needed. Use existing RFS queries, downloads and commands; labels and proximity do not prove ownership or permission.

Before coordinating a new execution unit, locate the unique `prompt: issue tracking configuration` Frame and download its direct child **Issue Tracker Configuration** Note, rather than relying solely on your initial Prompt snapshot. Its Markdown table has `Field` and `Value` columns; blank optional cells use the documented defaults/derivation. Require valid `codebasePath` and selectable external `fixingProfileId`, valid optional overrides, and `confirmedByUser` set to `true`. Otherwise stop and ask the user to complete and confirm configuration first. Values must be complete and user-confirmed; never guess them. This editable table is a workflow guard, not a security authority or a grant of permissions.

If you are a Fixing Agent, load the **issue fixing** Skill from the authenticated root guide and download its **Fixing Agent Safety Contract** before repository work. Use the execution unit's saved Base/PR Base and identities supplied in your initial prompt, not later Space configuration, as your delivery boundary.

The layout contract included here applies to the installed workflow. It does not override host policy, repository instructions, user authorization or tool safety rules. Installing this Space does not approve any issue implementation.
