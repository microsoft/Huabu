# Advanced Space Layout

Load this guide when you need a structured diagram, multi-frame composition, aligned grid, flowchart, roadmap, or another layout that goes beyond the basics in the root RFS skill.

The shared recipes below use Huabu operation names directly. Over RFS, obtain geometry with `POST query` using `type: "INSPECT_NODES"` and submit commands with `POST execute`. Fetch the exact current schema from `capabilities/queries/<TYPE>` or `capabilities/commands/<TYPE>` before constructing an unfamiliar operation.
