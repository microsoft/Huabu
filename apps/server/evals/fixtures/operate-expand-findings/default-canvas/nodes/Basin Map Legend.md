# Basin Map Legend

Reference only — colour and hatch symbols used on the printed basin map.
Not part of the survey narrative.

- Blue solid: perennial channel
- Blue dashed: intermittent channel
- Brown hatch: exposed sediment bar
- Red triangle: monitoring station
