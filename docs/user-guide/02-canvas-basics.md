# 02 · 画布使用

## 工具栏概览

工具栏固定在画布顶部中央，从左到右分为五个功能区：

### 指针 / 抓手

| 工具               | 图标 | 作用                             |
| ------------------ | ---- | -------------------------------- |
| **指针（Select）** | ↖    | 默认模式，点击选取节点、拖动节点 |
| **抓手（Pan）**    | ✋   | 平移视图，不会误触节点           |

> 按住 `Space` 可临时切换到抓手模式，松开自动恢复。按住**鼠标中键**拖动也可直接平移，无需切换工具。

---

### 节点创建按钮

| 按钮    | 节点类型 | 说明                             |
| ------- | -------- | -------------------------------- |
| ▭ Frame | 分组框   | 点击激活后，在画布空白处单击放置 |
| 📋 Note | 便签     | 同上                             |
| 𝐓 Text  | 文本块   | 同上                             |

**使用方法：**

1. 点击工具栏中对应图标（图标高亮表示已激活）
2. 移动鼠标到画布上，会出现预览占位
3. 在目标位置单击，节点创建完成
4. 再次点击图标或按 `Escape` 取消

---

### 上传文件

点击**上传**图标打开对话框：

- 支持格式：图片（PNG / JPG / GIF / WebP）、PDF、视频（MP4）
- 可同时选择多个文件批量上传
- 上传完成后自动创建对应类型的节点

> 也可以直接将文件从文件管理器**拖放**到画布上。

---

### 添加链接

点击**链接**图标打开输入框：

- 每行粘贴一个 URL
- 系统自动识别类型（图片 / PDF / 网页 / Youtube 视频），创建对应节点
- 按 `Ctrl/Cmd+Enter` 快速确认

---

### 布局按钮

| 按钮                | 作用                             | 快捷键             |
| ------------------- | -------------------------------- | ------------------ |
| ⊞ **布局全部**      | 对所有节点执行布局               | `Ctrl/Cmd+Shift+L` |
| ✨ **自动布局开关** | 开启后，新节点自动插入到合适位置 | `Ctrl/Cmd+Shift+A` |

开启时按钮高亮显示。详见 [05 · 自动布局](./05-auto-layout.md)。

---

### 意图按钮

点击 🧠 图标（或按 `Ctrl/Cmd+I`）触发意图识别。AI 分析当前画布状态，推荐可执行的操作建议。详见 [04 · 意图系统](./04-intent-system.md)。

---

## 节点

### 节点通用操作

所有节点都支持以下操作：

| 操作     | 方式                                     |
| -------- | ---------------------------------------- |
| 选中     | 单击                                     |
| 移动     | 拖拽                                     |
| 调整大小 | 拖拽边缘或角落                           |
| 展开查看 | 双击，或节点工具栏展开按钮               |
| 重命名   | 在展开面板中修改标题，或 AI 自动生成标题 |
| 删除     | 选中后按 `Delete` / `Backspace`          |
| 复制     | `Ctrl/Cmd+C` 后 `Ctrl/Cmd+V`             |

### 创建节点

| 方式             | 说明                                               |
| ---------------- | -------------------------------------------------- |
| 工具栏按钮       | 激活节点类型后，在画布单击放置                     |
| 拖放文件         | 从文件管理器直接拖入，支持图片、PDF、视频          |
| 粘贴文件         | `Ctrl/Cmd+V` 粘贴剪贴板中的文件                    |
| 粘贴 URL         | `Ctrl/Cmd+V`，每行一个 URL，自动识别类型           |
| 粘贴文本         | `Ctrl/Cmd+V`，纯文本自动创建 Note 节点             |
| 上传弹窗         | 批量上传本地文件                                   |
| 链接弹窗         | 批量粘贴 URL（每行一个）                           |
| Sources 面板拖拽 | 从 Sources 面板将知识库条目拖入画布，创建对应节点  |
| Chat 面板拖拽    | 从 Chat 面板将消息内容拖入画布                     |
| Note 节点        | 拖拽Note节点内的信息到画布                         |
| PDF Note 节点    | 选取PDF 节点中的部分文字或截图图片拖拽或加入到画布 |
| AI 生成          | 通过对话或意图系统，AI 自动在画布上创建节点        |

---

### 选择节点

- **单选**：点击节点
- **多选**：`Ctrl+点击` 逐个追加，或在空白处**拖拽框选**
- **取消**：点击画布空白处

---

### 展开节点

双击节点，在右侧面板中全屏预览与编辑内容。点击关闭按钮或在展开面板按ESC退出。

---

### 删除节点

选中节点后，按 `Delete` 或 `Backspace`。删除节点时，其所有连线一并移除。

---

## 移动与层级

### 移动

选中节点后直接拖拽。可同时拖动多个选中的节点。

### 层级调整

| 快捷键 | 效果                             |
| ------ | -------------------------------- |
| `[`    | 将选中节点置底（Send to Back）   |
| `]`    | 将选中节点置顶（Bring to Front） |

> 在canvas层级面板上拖动节点也可以调整层级。

---

## 连线与断线

### 建立连线

将鼠标悬停在节点边缘，出现连接点后，从该点拖拽到另一个节点即可。

### 断开连线

点击选中连线后，按 `Delete` 或 `Backspace`。

---

## Frame 分组

### 创建 Frame

- 工具栏点击 Frame 图标后在画布画出一个矩形，创建空 Frame。若拖动时有其他节点被框选，则这些节点会自动成为 Frame 的子节点。
- 选中若干节点后按 `Ctrl/Cmd+G`，自动群组到新 Frame

### 移入 / 移出 Frame

- **移入**：拖动节点到 Frame 区域内松开，自动成为子节点
- **移出**：将子节点拖到 Frame 边界外松开

---

## 复制与粘贴

| 操作         | 快捷键       |
| ------------ | ------------ |
| 复制选中节点 | `Ctrl/Cmd+C` |
| 粘贴         | `Ctrl/Cmd+V` |

粘贴时节点出现在当前鼠标位置。若剪贴板是外部内容（文件 / URL / 文本），按创建节点逻辑处理，见上方「创建节点」表格。

---

## 撤销与重做

| 操作         | 快捷键             |
| ------------ | ------------------ |
| 撤销（Undo） | `Ctrl/Cmd+Z`       |
| 重做（Redo） | `Ctrl/Cmd+Shift+Z` |

几乎所有画布操作（创建、移动、连线、删除、分组等）均可撤销。
