# 03 · 画布基础

画布是 Huabu 的主要工作空间：一块支持无限滚动与缩放的二维平面。本章覆盖画布的通用操作，节点本身的具体能力见 [04 · 节点详解](./04-nodes.md)。

---

## 顶部工具栏

工具栏固定在画布顶部中央，从左到右分为五个功能区。

### 1) 指针 / 抓手

| 工具               | 作用                             |
| ------------------ | -------------------------------- |
| **指针（Select）** | 默认模式，点击选取节点、拖动节点 |
| **抓手（Pan）**    | 平移视图，不会误触节点           |

> 按住 `Space` 可临时切换到抓手模式，松开自动恢复。**鼠标中键**拖动也可直接平移，无需切换工具。

### 2) 节点创建按钮

| 按钮    | 节点类型 | 操作                           |
| ------- | -------- | ------------------------------ |
| ▭ Frame | 分组框   | 点击激活后在画布上拖一个矩形   |
| 📋 Note | 便签     | 点击激活后在画布空白处单击放置 |
| 𝐓 Text  | 文本块   | 同上                           |

激活后图标高亮；再次点击或按 `Esc` 取消。

### 3) 上传文件

打开文件对话框，可批量上传：

- 图片（PNG / JPG / GIF / WebP / SVG）
- PDF
- 视频（MP4 / WebM / MOV / OGG）

也可以**直接从文件管理器拖放**到画布上。

### 4) 添加链接

打开输入框，每行粘贴一个 URL。系统会自动识别类型（图片 / PDF / 网页 / YouTube 视频）并创建对应节点。`Ctrl/Cmd+Enter` 快速确认。

### 5) 意图按钮

🧠 图标 / `Ctrl/Cmd+I` 触发意图识别。AI 分析当前画布状态，推荐 3–5 个可执行的下一步。详见 [07 · 意图系统](./07-intent.md)。

## 选择与多选

| 操作     | 方式                   |
| -------- | ---------------------- |
| 单选     | 点击节点               |
| 多选追加 | `Ctrl/Cmd+点击` 节点   |
| 框选     | 在空白处拖拽出一个选框 |
| 取消选择 | 点击画布空白处         |

多选后画布会出现**多选浮动工具栏**，提供：

- 对齐：左 / 中 / 右、上 / 中 / 下
- 分散：自动把重叠节点拉开
- 聚合到 Frame：一键把所选节点纳入新 Frame（也可直接按 `Ctrl/Cmd+G`）

## 创建节点（汇总）

| 方式          | 说明                                                  |
| ------------- | ----------------------------------------------------- |
| 工具栏按钮    | 激活节点类型后在画布单击放置                          |
| 拖放文件      | 从文件管理器直接拖入                                  |
| 粘贴文件      | `Ctrl/Cmd+V` 粘贴剪贴板中的图片 / PDF / 视频          |
| 粘贴 URL      | 每行一个 URL，自动识别类型                            |
| 粘贴文本      | 自动创建 Note 节点                                    |
| 上传弹窗      | 批量上传本地文件                                      |
| 链接弹窗      | 批量粘贴 URL                                          |
| Chat 面板拖拽 | 从 AI 对话消息拖一段内容到画布，自动创建 Note         |
| Note 内拖拽   | 在 Note 编辑器里把一个块拖到画布，拆出新节点          |
| PDF 选区      | 在 PDF 大屏选区，把文字 / 截图拖到画布                |
| AI 自动创建   | Operate 模式 / 意图执行 / Question 节点都会自动建节点 |

> **拖拽语义**：从可编辑的 Note 块拖到画布时，**默认是"移动"**（源 Note 中的该块会被删除）；按住 `Ctrl/Cmd` 拖拽则变为"复制"（源 Note 保留原文）。鼠标光标会同步显示是否带 `+` 来反馈当前模式。Chat 消息卡片、Web / Image 卡片、外部文件等无法回写的来源始终走"复制"，不受修饰键影响。

> **拖拽到已有 Note 上**：除了拖到画布空白处创建新节点之外，你也可以直接拖到一个**已有的 Note 节点**：
>
> - 拖到画布上的 **Note 瓦片**：内容会**追加到该 Note 末尾**（按 block 间隔分隔）。瓦片在拖拽悬停时高亮一圈蓝色环作为反馈。修饰键语义与上文一致：默认 Move（源块消失）、`Ctrl/Cmd` Copy（源保留）。
> - 拖到右侧**展开编辑面板**里的 Note：内容会**插入到光标所在 block 之后**，精确定位。Chat 消息块到当前编辑的 Note 是这条路径的典型用法。
> - 锁定的 Note 不接收拖入（事件继续冒泡到画布，行为退化为"在该位置新建节点"）。
> - 把 Note 的某块拖回它自己的瓦片或自己的展开编辑器里 → 由 Note 内部的 block-reorder 处理，不会触发画布逻辑。

## 移动与层级

- **移动**：选中后直接拖拽，可同时拖多个
- **置底 / 置顶**：`[`（送到底层） / `]`（提到顶层）
- 在左侧 **Layers 面板**也可以拖动节点调整层级，并锁定节点

锁定的节点（任何类型）：不可拖动、不可调整大小、自动布局中视为固定点；仍可删除和编辑内容。详见 [04 · 节点详解](./04-nodes.md#锁定固定节点-防止误操作)。

## 连线

| 操作     | 方式                                             |
| -------- | ------------------------------------------------ |
| 建立连线 | 鼠标悬停在节点边缘出现连接点，从该点拖到另一节点 |
| 选中连线 | 点击连线本体                                     |
| 断开连线 | 选中后按 `Delete` / `Backspace`                  |
| 改样式   | 选中连线后会出现边样式工具栏（粗细、颜色等）     |

AI 在 Operate 模式或意图执行中也会自动创建连线，用于表达"引用 / 来源 / 关联"。

---

## 复制 / 粘贴 / 撤销

| 操作 | 快捷键                 |
| ---- | ---------------------- |
| 复制 | `Ctrl/Cmd+C`           |
| 粘贴 | `Ctrl/Cmd+V`           |
| 删除 | `Delete` / `Backspace` |
| 撤销 | `Ctrl/Cmd+Z`           |
| 重做 | `Ctrl/Cmd+Shift+Z`     |

粘贴时节点出现在当前鼠标位置。剪贴板内容的具体处理见 [08 · 快捷键参考](./08-shortcuts.md#粘贴行为说明)。

几乎所有画布操作（创建、移动、连线、删除、分组、布局）都可撤销。AI 在 Operate 模式下产生的批量变更有专门的"变更清单"管理，详见 [06 · 人机协作](./06-ai-collaboration.md#operate-模式)。

## 侧边面板

画布两侧各有一个可折叠的面板：

- **左侧 · Layers**（[CanvasLayerPanel](../../apps/web/src/components/Panels/CanvasLayerPanel)）
  - 以树状结构显示当前画布的所有节点 / Frame 层级，可拖拽改变层级、锁定、重命名
- **右侧 · Chat**（[ChatPanel](../../apps/web/src/components/Panels/ChatPanel)）
  - 与 AI 的对话面板，支持 Ask / Operate 两种模式

详见 [05 · Sources 与知识库](./05-sources-and-knowledge.md) 和 [06 · 人机协作](./06-ai-collaboration.md)。
