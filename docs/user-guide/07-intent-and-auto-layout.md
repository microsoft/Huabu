# 07 · 意图与自动布局

意图系统和自动布局都属于"AI 帮你**组织画布**"的能力 —— 一个负责想"接下来做什么"，另一个负责想"放在哪里"。

---

## 意图系统（Intent System）

意图系统让 AI 基于**当前画布状态 + 你的近期操作**，推荐若干"接下来可以做的事"，并把每个建议变成一组可一键执行的具体操作。

### 触发方式

| 方式   | 说明                             |
| ------ | -------------------------------- |
| 键盘   | `Ctrl/Cmd+I`                     |
| 工具栏 | 顶部工具栏的大脑图标 🧠          |
| 批注   | 选中 Sketch 节点后让 AI 解释意图 |

触发后会在按钮附近弹出 **Intent Popover**。

### 两步工作流

**步骤一：选择意图**

系统把画布概览（节点摘要 + 近期操作）发给 AI，由它流式生成 3–5 个候选意图，例如：

- "对选中的三篇文章生成对比总结"
- "把搜索结果节点整理到新 Frame 中"
- "为当前画布创建思维导图结构"

你也可以在输入框里**自由输入**自定义意图。

**步骤二：解析为操作**

选择或输入意图后，系统切换到 [Operate 模式](./06-ai-collaboration.md#operate-模式)，让 AI 把意图解析成一组具体的画布命令（创建节点、连线、移入 Frame…）并执行。结果会出现在画布上，并附带变更清单可整体撤销。

### 意图历史

每次完成的意图执行都被记成一个 episode 存到本地，便于后续优化推荐与排查。

---

## 自动布局（Auto Layout）

布局引擎基于力导向算法，根据节点之间的**显式连线**和**隐式语义关系**自动排列位置。

### 布局动作

| 动作         | 范围         | 触发                               | 效果                                   |
| ------------ | ------------ | ---------------------------------- | -------------------------------------- |
| **自动放置** | 单个新建节点 | 开启自动布局后新节点创建时自动触发 | 把新节点插到关联节点附近，其余节点不动 |

> 早期版本提供的“布局全部”与“布局 Frame”一键重排已下线；调整位置请手动拖动，或依赖“自动放置”在创建新节点时生效。

所有布局动作都可用 `Ctrl/Cmd+Z` 撤销。

### 自动布局开关

工具栏 ✨ 图标（`Ctrl/Cmd+Shift+A`）控制**增量自动放置**是否启用：

- **开启**（按钮高亮）：每个新创建的节点自动放到合适位置；Frame 自动调整大小以包裹子节点；拖动节点时显示目标 Frame 的预览边框
- **关闭**（默认）：新节点出现在画布中央，不自动移动

### 隐式语义边

布局引擎不只看你手动连的线，还会识别这些**隐式关系**并把相关节点拉近：

| 关系类型     | 权重  | 说明                                     |
| ------------ | ----- | ---------------------------------------- |
| 用户连线     | `1.0` | 你手动绘制的画布连线                     |
| 研究引用     | `0.6` | 合成节点 → 它引用的来源节点              |
| 知识来源     | `0.4` | 节点 → 其所属的 Source 节点              |
| 同一研究线程 | `0.3` | 同一次 AI 研究会话产生的节点（两两连接） |
| 同一对话线程 | `0.3` | 从同一聊天线程拖出的节点（两两连接）     |
| 同一 Frame   | `0.2` | 同一 Frame 内的兄弟节点（两两连接）      |

> 两节点间存在多种关系时只取**权重最高**的一条，不累加。

### 布局算法

| 场景           | 算法                 | 特点                                       |
| -------------- | -------------------- | ------------------------------------------ |
| 自动放置新节点 | **fCoSE** + 固定约束 | 现有节点位置完全固定，只算新节点的最优落点 |

fCoSE 原生支持 Frame 复合节点和断连图（多个孤立节点组）。

### 使用建议

- **研究过程中**：开启自动布局，让 AI 生成的节点自动聚集到关联内容旁
- **精细调整后**：关闭自动布局以防被自动改动；锁定关键节点
- **Frame 内整理**：在 Frame 里拖动节点手动调整布局，不影响画布其他部分
