# 07 · 意图系统（Intent）

意图系统让 AI 基于**当前画布状态 + 你的近期操作**，推荐若干"接下来可以做的事"，并把每个建议变成一组可一键执行的具体操作。

---

## 触发方式

| 方式   | 说明                             |
| ------ | -------------------------------- |
| 键盘   | `Ctrl/Cmd+I`                     |
| 工具栏 | 顶部工具栏的大脑图标 🧠          |
| 批注   | 选中 Sketch 节点后让 AI 解释意图 |

触发后会在按钮附近弹出 **Intent Popover**。

---

## 两步工作流

**步骤一：选择意图**

系统把画布概览（节点摘要 + 近期操作）发给 AI，由它流式生成 3–5 个候选意图，例如：

- "对选中的三篇文章生成对比总结"
- "把搜索结果节点整理到新 Frame 中"
- "为当前画布创建思维导图结构"

你也可以在输入框里**自由输入**自定义意图。

**步骤二：解析为操作**

选择或输入意图后，系统切换到 [Operate 模式](./06-ai-collaboration.md#operate-模式)，让 AI 把意图解析成一组具体的画布命令（创建节点、连线、移入 Frame…）并执行。结果会出现在画布上，并附带变更清单可整体撤销。

---

## 意图历史

每次完成的意图执行都被记成一个 episode 存到本地，便于后续优化推荐与排查。

---

## 画布上的节点位置

Huabu 不再提供"一键重排"或"力导向自动布局"。所有新节点都有**明确的创建位置**：

- **你手动创建**（拖拽、粘贴、输入框）：出现在说明性位置（指针位置 或 当前视窗中心）。
- **AI 创建**（意图 / Operate 模式中的 `CREATE_NODES`）：AI 必须在命令里给出明确的 `position`，不会再被"智能"重排。

调整位置请手动拖动；成组节点可以用[选中后的对齐 / 分布工具栏](./03-canvas-basics.md)进行整理。要让一组节点位置按"纵列 / 横行"自动打包，请把它们放进 [Frame](./04-nodes.md#frame--分组容器)：Frame 仍然会根据 `layout: column | row` 自动排列子节点。
