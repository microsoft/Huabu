# 03 · 节点详解

Sediment 共有 7 种节点类型，每种节点承载不同类型的内容，具备不同的交互方式。

---

## Note（便签）

**图标**：📋 **适合**：笔记、想法、摘要、AI 生成的文字内容

Note 节点是最常用的内容节点，支持富文本编辑（底层使用 BlockNote 编辑器）。

| 特性     | 说明                                             |
| -------- | ------------------------------------------------ |
| 编辑方式 | 双击节点直接在节点内编辑；或双击打开右侧展开面板 |
| 格式支持 | Markdown 语法，支持标题、加粗、列表、代码块等    |
| 高度     | 自动根据内容伸缩，无需手动调整                   |
| 宽度     | 默认 400px，可拖拽边缘调整                       |
| 知识库   | ✅ 可被索引到知识库，供 AI 检索引用              |

**典型用途**：

- 记录研究笔记、会议纪要
- AI Agent 生成的分析、总结
- 标注其他节点的背景说明

---

## Text（文本块）

**图标**：T **适合**：标题、标签、简短说明文字

Text 节点是纯文本块，比 Note 更轻量，适合作为画布上的标注或标题使用。

| 特性     | 说明                                 |
| -------- | ------------------------------------ |
| 编辑方式 | 双击直接编辑                         |
| 格式支持 | 纯文本，支持字体大小、粗细等样式调整 |
| 高度     | 自动伸缩                             |
| 知识库   | ❌ 不索引到知识库                    |

---

## Web（网页）

**图标**：🌐 **适合**：收藏网页、在线文章、参考链接

Web 节点嵌入式展示一个网页。创建时只需粘贴 URL。

| 特性     | 说明                       |
| -------- | -------------------------- |
| 创建方式 | 粘贴 URL、工具栏链接弹窗   |
| 展示方式 | 节点内嵌入式预览（iframe） |
| 展开面板 | 双击后在右侧面板中大屏浏览 |
| 知识库   | ✅ AI 可抓取网页内容并索引 |

> 部分网站因安全策略（X-Frame-Options）拒绝嵌入，此时节点显示链接而非内容预览。

---

## PDF

**图标**：📖 **适合**：论文、报告、说明文档

PDF 节点在画布上渲染 PDF 文件，支持多页预览。

| 特性     | 说明                                      |
| -------- | ----------------------------------------- |
| 创建方式 | 上传本地 PDF、粘贴 PDF 文件、粘贴 PDF URL |
| 展示方式 | 节点内显示首页预览                        |
| 展开面板 | 双击后可逐页翻阅                          |
| 下载     | 节点工具栏提供下载按钮                    |
| 知识库   | ✅ AI 可提取 PDF 文本内容并索引           |

---

## Video（视频）

**图标**：🎬 **适合**：教程视频、演示录屏、素材

Video 节点支持视频播放器。

| 特性     | 说明                                     |
| -------- | ---------------------------------------- |
| 支持格式 | MP4、WebM、OGG、MOV                      |
| 创建方式 | 上传本地视频、粘贴视频文件、粘贴视频 URL |
| 展示方式 | 节点内嵌入播放器，支持播放/暂停          |
| 展开面板 | 双击后大屏播放                           |
| 知识库   | ✅ 可关联知识库（文件路径存储）          |

---

## Image（图片）

**图标**：🖼️ **适合**：截图、图表、设计稿、参考图

Image 节点展示图片，并自动根据原始宽高比例计算显示尺寸。

| 特性     | 说明                                           |
| -------- | ---------------------------------------------- |
| 支持格式 | PNG、JPG、GIF、WebP、SVG                       |
| 创建方式 | 上传本地图片、粘贴图片（截图）、粘贴图片 URL   |
| 展开面板 | 双击后全屏查看                                 |
| 自动尺寸 | 上传时自动读取原始分辨率，按比例缩放至合适大小 |
| 知识库   | ✅ 可关联知识库（文件路径存储）                |

> 💡 直接按 `Ctrl/Cmd+V` 可粘贴剪贴板中的截图，自动创建 Image 节点。

---

## Frame（分组框）

**图标**：🗂️ **适合**：按主题或阶段对节点进行分组

Frame 是一个可以包含其他节点的容器，用于在画布上创建视觉分组。

| 特性     | 说明                                                   |
| -------- | ------------------------------------------------------ |
| 子节点   | 拖入 Frame 区域的节点自动成为子节点，随 Frame 一起移动 |
| 锁定     | 工具栏锁定后，子节点无法单独移动，Frame 作为整体操作   |
| 独立布局 | Frame 工具栏有独立的"布局子节点"按钮                   |
| 自动调整 | 开启自动布局时，Frame 自动收缩/扩展以包裹所有子节点    |
| 嵌套     | 支持 Frame 嵌套（Frame 内含 Frame）                    |

**Frame 工具栏操作**（选中 Frame 后显示）：

| 按钮     | 功能                              |
| -------- | --------------------------------- |
| 锁定图标 | 切换锁定状态                      |
| 布局图标 | 对 Frame 内所有子节点执行自动布局 |
| 解散图标 | 解散 Frame，子节点保留在原位      |
