# 03 · 节点详解

Sediment 共有 7 种节点类型，每种节点承载不同类型的内容，具备不同的交互方式。

---

## 节点通用能力

### 1) 展开（右侧大屏 / 编辑面板）

- **除 Text 外的内容节点（Note / Web / PDF / Image / Video）**：双击节点，会在右侧打开大屏预览/编辑面板；也可以点击该节点的工具栏按钮进入大屏。
- **Text**：双击进入**原地编辑**（不进入右侧面板）。

### 2) 每个节点都有自己的“节点工具栏”（单选时出现）

当你**选中一个节点**（且当前只选中一个）时，节点上方会出现一个小工具栏。不同类型节点的工具栏不同，但遵循同一个原则：

- **内容类节点（Note / Web / PDF / Image / Video）**通常提供“打开大屏”等快捷操作。
- **Text**的工具栏主要是文字样式（字体、加粗/斜体/下划线/删除线、文字色、背景色等）。
- **Frame**的工具栏用于对分组进行“布局/解散”等操作。

为了便于快速记忆，这里给一个**工具栏功能速览（当前版本）**：

- **Note**：打开大屏、复制内容
- **Web**：打开原网页（新标签页）、打开大屏
- **PDF**：打开大屏、下载、删除封面（当已设置封面时）
- **Image / Video**：打开大屏
- **Text**：字体/字号、加粗/斜体/下划线/删除线、文字色、背景色
- **Frame**：布局子节点、解散分组

### 3) 多选：对齐 / 分散 / 聚合 Frame

- 多选后，画布会出现一个**多选浮动工具栏**，可以对齐（左/中/右、上/中/下）或把重叠节点“分散开”。
- 多选节点还可以**聚合成 Frame**：
  - 选中多个节点后按 `Ctrl/Cmd+G`，会创建一个新 Frame，并把这些节点作为子节点放进去。
  - 或者切换到 Frame 工具，在画布上拖出一个矩形；拖拽过程中被框选的节点会自动成为该 Frame 的子节点。

### 4) 锁定（固定节点 / 防止误操作）

在画布的**层级面板（图层列表）**中，每个节点行右侧都有锁定按钮（悬停出现），可一键**锁定 / 解锁**。锁定适用于**所有节点类型**，不仅限于 Frame。

**锁定后的通用效果（所有节点类型）：**

- **不可拖动**：锁定节点无法在画布上拖动。
- **不可选中**：锁定节点无法通过画布上的手柄调整尺寸。
- **自动布局固定**：锁定节点在自动布局中被视为"固定点"，不会被重新定位或调整尺寸。
- **仍可删除**：锁定节点可以通过层级面板等方式删除。
- **仍可编辑内容**：锁定节点的内容可通过右侧面板或层级面板编辑（如重命名）。

**锁定 Frame 的额外效果：**

- **子节点不可单独拖动**：锁定 Frame 的所有子节点都会被禁止拖动（但子节点仍可选中）。
- **子节点在自动布局中也被固定**：子节点会继承父 Frame 的锁定状态，不会被自动布局重新定位。
- **不可纳入/移出子节点**：锁定 Frame 不会接收新的子节点（拖拽节点到锁定 Frame 上无效），也不会释放已有子节点。
- **不会自动调整尺寸**：锁定 Frame 不再自动收缩/扩展以包裹子节点。
- **仍可解散**：锁定 Frame 依然可以通过"解散分组"操作解散。

## Note（便签）

**图标**：📋 **适合**：笔记、想法、摘要、AI 生成的文字内容

Note 节点是最常用的内容节点，支持富文本编辑。

| 特性       | 说明                                                                                                        |
| ---------- | ----------------------------------------------------------------------------------------------------------- |
| 编辑方式   | 双击展开右侧编辑面板                                                                                        |
| 格式支持   | Markdown 语法，支持标题、加粗、列表、代码块等                                                               |
| 拖拽到画布 | 在右侧编辑面板中，可用块左侧的拖拽把手把**一段内容**拖到画布，快速生成新的 Note（适合把长笔记拆成多个节点） |
| 节点工具栏 | 打开大屏、复制内容                                                                                          |

---

## Text（文本块）

**图标**：T **适合**：标题、标签、简短说明文字

Text 节点是纯文本块，比 Note 更轻量，适合作为画布上的标注。

| 特性       | 说明                                                 |
| ---------- | ---------------------------------------------------- |
| 编辑方式   | 双击直接原地编辑                                     |
| 格式支持   | 纯文本，支持字体大小、粗细等样式调整                 |
| 节点工具栏 | 字体/字号、加粗/斜体/下划线/删除线、文字色、背景色等 |

---

## Web（网页）

**图标**：🌐 **适合**：收藏网页、在线文章、参考链接

Web 节点嵌入式展示一个网页。创建时只需粘贴 URL。

| 特性       | 说明                             |
| ---------- | -------------------------------- |
| 创建方式   | 粘贴 URL、工具栏链接弹窗         |
| 节点工具栏 | 打开原网页（新标签页）、打开大屏 |

---

## PDF

**图标**：📖 **适合**：论文、报告、说明文档

PDF 节点在画布上渲染 PDF 文件，支持多页预览。

| 特性       | 说明                                                                                                                                                                    |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 创建方式   | 上传本地 PDF、粘贴 PDF 文件、粘贴 PDF URL                                                                                                                               |
| 下载       | 节点工具栏提供下载按钮                                                                                                                                                  |
| 选区提取   | 在右侧 PDF 大屏中可进入“选区”模式：框选任意区域（也可以框到整页/大范围）后，会出现一个小浮动面板；支持把**选区文字拖到画布生成 Note**、把**选区截图拖到画布生成 Image** |
| 封面       | 选区截图可一键设置为该 PDF 节点的封面（节点将显示封面图）；已设置封面时，可在节点工具栏中删除封面以恢复多页预览                                                         |
| 直接聊天   | 选区截图可一键发送到 Chat 作为待发送附件（可用于让 AI 基于该片段回答/总结；若选区中提取到文字，会一并附带）                                                             |
| 节点工具栏 | 打开大屏、下载、删除封面（当已设置封面时）                                                                                                                              |

---

## Video（视频）

**图标**：🎬 **适合**：教程视频、演示录屏、素材

Video 节点支持视频播放器。

| 特性       | 说明                                     |
| ---------- | ---------------------------------------- |
| 支持格式   | MP4、WebM、OGG、MOV                      |
| 创建方式   | 上传本地视频、粘贴视频文件、粘贴视频 URL |
| 节点工具栏 | 打开大屏                                 |

---

## Image（图片）

**图标**：🖼️ **适合**：截图、图表、设计稿、参考图

Image 节点展示图片，并自动根据原始宽高比例计算显示尺寸。

| 特性       | 说明                                         |
| ---------- | -------------------------------------------- |
| 支持格式   | PNG、JPG、GIF、WebP、SVG                     |
| 创建方式   | 上传本地图片、粘贴图片（截图）、粘贴图片 URL |
| 节点工具栏 | 打开大屏                                     |

> 💡 直接按 `Ctrl/Cmd+V` 可粘贴剪贴板中的截图，自动创建 Image 节点。

---

## Frame（分组框）

**图标**：🗂️ **适合**：按主题或阶段对节点进行分组

Frame 是一个可以包含其他节点的容器，用于在画布上创建视觉分组。

| 特性       | 说明                                                                                                                      |
| ---------- | ------------------------------------------------------------------------------------------------------------------------- |
| 子节点     | 拖入 Frame 区域的节点自动成为子节点，随 Frame 一起移动                                                                    |
| 聚合创建   | 多选节点后按 `Ctrl/Cmd+G` 可一键创建 Frame 并自动纳入所选节点                                                             |
| 锁定       | 可在层级面板锁定/解锁；锁定后子节点不可拖动（但仍可选中）、不会自动纳入/移出子节点、不会自动调整尺寸；锁定 Frame 仍可解散 |
| 独立布局   | Frame 工具栏有独立的“布局子节点”按钮                                                                                      |
| 自动调整   | 开启自动布局时，Frame 自动收缩/扩展以包裹所有子节点                                                                       |
| 嵌套       | 支持 Frame 嵌套（Frame 内含 Frame）                                                                                       |
| 节点工具栏 | 布局子节点、解散 Frame                                                                                                    |
