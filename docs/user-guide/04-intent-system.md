# 04 · 意图系统

意图系统（Intent System）是 Sediment 的核心 AI 功能之一。它能根据当前画布的状态和你的操作历史，**推测你接下来想做什么**，并将复杂的多步操作转化为一键可执行的操作序列。

---

## 触发方式

| 方式   | 说明                           |
| ------ | ------------------------------ |
| 键盘   | `Ctrl/Cmd+I`                   |
| 工具栏 | 点击顶部工具栏的大脑图标（🧠） |

触发后，意图识别浮层（Intent Popover）出现在触发按钮附近。

---

## 两步工作流

意图系统分为两个步骤：

### 步骤一：选择意图

系统自动分析当前状态（包含画布截图 + 节点摘要 + 近期操作历史），由 AI 生成 **3–5 个候选意图**，每个候选都描述一个可能的下一步目标。

例如：

- "对选中的三篇文章生成对比总结"
- "将搜索结果节点整理到新 Frame 中"
- "为当前画布创建思维导图结构"

你也可以在输入框中**自由输入**自定义意图。

### 步骤二：确认操作

选择或输入意图后，系统将意图解析为一系列具体的**原子操作**（Action），例如：

- 创建 Note 节点（内容为 AI 生成的摘要）
- 连线到来源节点
- 将节点移入指定 Frame

操作列表会显示出来供你**预览和编辑**。确认无误后点击执行，所有操作按顺序自动完成。

---

## 操作类型

意图可以执行的操作包括：

| 操作               | 说明                               |
| ------------------ | ---------------------------------- |
| `ADD_NODE`         | 创建新节点（指定类型、内容、位置） |
| `UPDATE_NODE`      | 修改已有节点的内容或标题           |
| `CONNECT`          | 在两个节点之间建立连线             |
| `MOVE_INTO_FRAME`  | 将节点移入指定 Frame               |
| `GROUP_INTO_FRAME` | 将多个节点群组到新 Frame           |
| `DELETE_NODES`     | 删除指定节点                       |
| `SELECT_NODES`     | 选中指定节点                       |

新建节点时支持 `$new1`、`$new2` 等占位符 ID，后续的连线等操作可引用这些占位符，系统会自动解析为实际节点 ID。

---

## 典型使用场景

### 场景一：快速总结

在画布上选中几个 Web 或 PDF 节点 → 按 `Ctrl+I` → 选择"为选中节点生成总结" → 系统自动创建包含摘要内容的 Note 节点并连线到来源节点。

### 场景二：结构整理

画布上已有多个散乱节点 → 按 `Ctrl+I` → 选择"按主题分组到 Frame" → 系统根据节点内容的语义相似度自动创建 Frame 并整理。

### 场景三：自定义任务

按 `Ctrl+I` → 切换到输入框 → 输入"帮我比较节点 A 和节点 B 的主要观点" → 系统解析并执行。

---

## 上下文来源

意图识别使用以下信息作为上下文：

| 信息       | 说明                                          |
| ---------- | --------------------------------------------- |
| 画布截图   | 当前可视区的快照，帮助 AI 理解布局            |
| 节点摘要   | 所有节点的类型、标题、内容片段（前 120 字符） |
| 选中节点   | 当前选中节点的完整内容                        |
| 近期操作   | 最近的编辑、创建、移动等操作历史              |
| Frame 结构 | 节点的分组和父子关系                          |

---

## 注意事项

- 意图执行产生的所有画布操作均**可撤销**（`Ctrl/Cmd+Z`）
- 步骤二中可以手动编辑操作列表，删除不需要的步骤再执行
- 点击"返回"可回到步骤一重新选择意图
