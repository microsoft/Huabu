# 04 · 意图系统

意图系统（Intent System）是 Sediment 的核心 AI 功能之一。它能根据当前画布的状态和你的操作历史，**推测你接下来想做什么**，并将复杂的多步操作转化为一键可执行的操作序列。

---

## 触发方式

| 方式   | 说明                           |
| ------ | ------------------------------ |
| 键盘   | `Ctrl/Cmd+I`                   |
| 工具栏 | 点击顶部工具栏的大脑图标（🧠） |

触发后，意图识别浮层（Intent Popover）出现在触发按钮附近。

---

## 两步工作流

意图系统分为两个步骤：

### 步骤一：选择意图

系统自动分析当前状态（包含画布截图 + 节点摘要 + 近期操作历史），由 AI 生成 **3–5 个候选意图**，每个候选都描述一个可能的下一步目标。

例如：

- "对选中的三篇文章生成对比总结"
- "将搜索结果节点整理到新 Frame 中"
- "为当前画布创建思维导图结构"

你也可以在输入框中**自由输入**自定义意图。

### 步骤二：确认操作

选择或输入意图后，系统将意图解析为一系列具体的**原子操作**（Action），例如：

- 创建 Note 节点（内容为 AI 生成的摘要）
- 连线到来源节点
- 将节点移入指定 Frame

操作列表会显示出来供你**预览和编辑**。确认无误后点击执行，所有操作按顺序自动完成。
