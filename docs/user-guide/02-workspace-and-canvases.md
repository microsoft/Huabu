# 02 · 工作区与画布

Huabu 的所有用户数据都落在你**自己选定的一个本地文件夹**（工作区）下。一个工作区可以容纳任意多张画布，以及一个共享的 Sources（知识来源）库。

---

## 首次启动：选择工作区

第一次打开应用时会出现工作区选择页：

| 操作       | 说明                                           |
| ---------- | ---------------------------------------------- |
| 选择文件夹 | 通过系统原生对话框选择一个本地文件夹作为工作区 |
| 最近工作区 | 列出之前用过的工作区，可一键打开或从列表中移除 |

应用会在选定的文件夹下自动创建以下子目录（如不存在）：

```
<workspace>/
├── canvas/         画布 JSON 文件
├── sources/        知识来源（Markdown + frontmatter）
├── artifacts/      上传/AI 生成的二进制附件（图片、PDF、视频）
└── .history/       对话历史（按 canvas + 线程划分）
```

工作区的选择会被记在浏览器 localStorage 中，下次启动会自动加载上次的工作区。

---

## 切换工作区

随时可以通过设置切换到另一个工作区。切换后画布列表、Sources 列表、对话历史都会切换到新工作区下的内容；旧工作区的文件不会被改动。

> 💡 工作区是**纯文件夹**，可以直接用 Git、iCloud、Dropbox 等任意方式同步或备份。

---

## 画布列表（Home）

进入工作区后看到的是画布列表页：

| 操作     | 说明                                                      |
| -------- | --------------------------------------------------------- |
| 新建画布 | 在工作区中新建一张空白画布                                |
| 打开画布 | 点击列表中的画布卡片进入                                  |
| 删除画布 | 卡片上的删除按钮，会同时清除该画布的对话历史              |
| 导出画布 | 导出为 `.canvas.json` 文件，包含节点、连线、版本号        |
| 导入画布 | 从 `.canvas.json` 文件创建一张新画布（会分配新的画布 ID） |

页面顶部还会显示工作区的 **Sources 数量**入口，点击进入 [Sources 列表页](./05-sources-and-knowledge.md)。

---

## 一张画布的生命周期

1. **新建** — 在画布列表点"新建"，自动跳转进新画布
2. **编辑** — 在画布上添加节点、连线、调用 AI（详见后续章节）
3. **自动保存** — 每次操作都会原子性写回 `canvas/<canvasId>.json`（先写 `.tmp` 再 rename），不会因为中途崩溃损坏文件
4. **版本号** — 画布文件包含版本号，前端打开时会校验
5. **导出/分享** — 任何时候都可以导出为单文件 `.canvas.json`

---

## 与多人协作

当前版本是**单机本地优先**的：一张画布同时只期望被一个客户端编辑。如果你需要把工作分享给他人，建议：

- 通过**导出/导入**传递整张画布的快照
- 或者把整个工作区文件夹放进版本控制 / 同步盘

跨设备实时协同尚未提供。
