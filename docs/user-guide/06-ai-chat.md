# 06 · AI 对话

Sediment 内置了一个与画布深度集成的 AI 对话界面。你可以用自然语言向 AI 提问或下达指令，AI 不仅能回答问题，还能**直接在画布上创建和修改节点**。

---

## 打开对话面板

点击界面左侧（或右侧，取决于布局）的聊天图标，展开对话面板。

---

## 基本使用

在输入框中输入消息，按 `Enter` 或点击发送按钮。

AI 的回复会以消息气泡的形式出现。如果 AI 在回复过程中操作了画布（创建节点、建立连线等），你会在画布上实时看到变化。

---

## 上下文感知

AI 在每次对话时都能"看到"当前画布的内容：

| 上下文信息     | 说明                                           |
| -------------- | ---------------------------------------------- |
| **节点摘要**   | 所有节点的类型、标题、内容片段（前 120 字符）  |
| **Frame 结构** | 节点的分组和父子关系                           |
| **选中节点**   | 当前选中节点的**完整内容**（不截断）           |
| **近期操作**   | 最近的画布操作历史，帮助 AI 理解当前任务上下文 |
| **知识库**     | AI 可主动检索已索引的节点内容                  |

> 💡 **技巧**：在问问题之前先选中相关节点，AI 会优先关注这些节点的完整内容。

---

## AI 可以做什么

### 回答问题

直接提问即可：

- "帮我总结一下画布上的所有 PDF 内容"
- "这几篇文章的核心观点有什么区别？"
- "帮我翻译这个 Note 节点"

### 在画布上创建内容

AI 可以主动创建节点作为对话的输出：

- "将你的分析结果创建为一个新的 Note 节点"
- "为每个主题创建一个 Frame，把相关节点整理进去"
- "搜索 XXX 并把结果添加到画布"

### 调用工具

AI Agent 可以调用后端工具完成更复杂的任务：

| 工具         | 说明                       |
| ------------ | -------------------------- |
| 搜索网络     | 搜索并返回相关网页内容     |
| 读取节点内容 | 获取指定节点的完整文字内容 |
| 创建节点     | 在画布指定位置创建新节点   |
| 连接节点     | 在两个节点之间建立连线     |
| 创建 Frame   | 创建分组框并添加子节点     |
| 检索知识库   | 在已索引的内容中语义搜索   |

---

## 多轮对话

每个聊天线程（Thread）保持完整的对话历史，AI 能记住之前的问答。

- 对话历史持久化存储在本地数据库（`langgraph-checkpoints.sqlite`）
- 重启应用后，历史对话仍然保留
- 不同的研究主题建议使用不同的线程，保持上下文清晰

---

## 从对话到画布

对话中 AI 生成的节点会带有 `chat` 来源标记，自动布局时会与同一线程的其他节点聚集在一起（见 [05 · 自动布局](./05-auto-layout.md)）。

你也可以将聊天消息中的内容**直接拖到画布上**，创建为 Note 节点。

---

## 注意事项

- AI 回复的质量取决于 LLM 提供商的模型能力，请确保 `.env` 中配置了有效的 API Key
- 复杂指令（如"整理整个画布"）可能需要几秒到几十秒
- AI 的画布操作和普通操作一样，均可通过 `Ctrl/Cmd+Z` 撤销
