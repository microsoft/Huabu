# 06 · AI 对话

Sediment 内置了一个与画布深度集成的 AI 对话界面。对话面板提供了三种工作模式——**Chat**、**Deep Research** 和 **Agent**——覆盖从日常问答到自动化研究再到精确画布操控的全场景需求。

---

## 打开对话面板

点击界面左侧（或右侧，取决于布局）的聊天图标，展开对话面板。

---

## 三种模式概览

在输入框左侧的模式选择器中，可以随时切换当前模式：

| 模式              | 图标        | 适用场景                                 |
| ----------------- | ----------- | ---------------------------------------- |
| **Chat**          | 💬 对话气泡 | 快速问答、总结、翻译、日常对话           |
| **Deep Research** | 🔍 搜索     | 多源网络调研，自动生成研究节点与综述     |
| **Agent**         | 🧠 大脑     | 用自然语言描述画布变更，预览后再确认应用 |

三种模式共享同一个消息列表和对话线程，你可以在同一次会话中自由切换。

---

## Chat 模式

Chat 是默认的对话模式，适合快速问答和轻量级画布操作。

### 工作方式

在输入框中输入消息，按 `Enter` 发送。AI 的回复会以流式消息气泡的形式逐字出现。如果 AI 在回复过程中决定操作画布（创建节点、建立连线等），你会在画布上实时看到变化。

### 上下文感知

AI 在每次对话时都能"看到"当前画布的内容：

| 上下文信息     | 说明                                             |
| -------------- | ------------------------------------------------ |
| **节点摘要**   | 所有节点的类型、标题、内容片段（前 120 字符）    |
| **Frame 结构** | 节点的分组和父子关系                             |
| **选中节点**   | 当前选中节点的**完整内容**（不截断）             |
| **近期操作**   | 最近的画布操作历史，帮助 AI 理解当前任务上下文   |
| **知识库**     | 选中节点若已被索引，其入库内容会自动注入为上下文 |

> 💡 **技巧**：在问问题之前先选中相关节点，AI 会优先关注这些节点的完整内容。

### 可用工具

Chat 模式下，AI 可以按需调用以下工具：

| 工具     | 说明                                     |
| -------- | ---------------------------------------- |
| 搜索网络 | 通过 Tavily 搜索互联网并返回相关网页内容 |

AI 会根据对话内容**自主决定**是否调用工具——你只需用自然语言提出需求即可。

### 示例

- "帮我总结一下画布上的所有 PDF 内容"
- "这几篇文章的核心观点有什么区别？"
- "搜索最新的 AI Agent 框架，并在画布上创建一个笔记"

## Deep Research 模式

Deep Research 是一个**全自动多步研究流水线**，适合需要系统性调研某个主题的场景。发送一条研究查询后，AI 会自主完成从搜索到整理的全过程，无需人工干预。

### 工作流程

Deep Research 按以下五个阶段依次执行：

1. **查询分析** — AI 将你的问题拆解为 2–4 个聚焦的子查询，确保搜索覆盖面
2. **多源搜索** — 对每个子查询执行网络搜索，并为每条搜索结果在画布上创建一个 Web 节点
3. **内容入库** — 自动将搜索结果的内容提取并索引到知识库，供后续检索使用
4. **综合分析** — AI 阅读所有搜索结果，生成一份结构化的综述笔记节点
5. **画布整理** — 将本次研究生成的所有节点（Web 节点 + 综述节点）归入一个带有标题的 Frame 中

### 研究配置

| 选项         | 说明                                         |
| ------------ | -------------------------------------------- |
| 搜索深度     | `基础`（3–5 个来源）或 `深入`（8–10 个来源） |
| 放置位置     | 研究结果在画布上的放置策略（自动布局等）     |
| 分组到 Frame | 是否将所有结果节点归入一个 Frame（默认开启） |

### 示例

- "调研 2025 年大语言模型在医疗领域的最新应用"
- "比较 React、Vue、Svelte 三个前端框架的优缺点"
- "搜索关于气候变化对农业影响的研究报告"

> 💡 研究过程中，你可以在面板中实时看到每个阶段的进度。所有创建的节点都会带有来源标记，并自动入库到知识库。

## Agent 模式

Agent 模式让你用自然语言**精确描述想要的画布变更**，AI 会将描述解析为具体的操作指令，应用到画布后提供**变更预览**，你可以逐条审查并决定保留还是撤销。

### 工作流程

1. 在输入框中描述你想要的画布变更
2. AI 通过意图识别系统将你的描述解析为一组结构化操作（创建节点、移动、分组等）
3. 操作立即应用到画布上，同时显示变更清单
4. 你可以在变更清单中：
   - **保留全部** — 确认所有变更
   - **撤销全部** — 恢复到操作前的快照
   - **逐条查看** — 审查每个操作的细节

### 与 Chat 模式的区别

| 对比项   | Chat                       | Agent                            |
| -------- | -------------------------- | -------------------------------- |
| 画布操作 | AI 自主决定是否操作        | 所有操作都可预览和撤销           |
| 响应方式 | 流式逐字输出               | 同步返回操作列表                 |
| 适用场景 | 问答、搜索、轻量创建       | 批量整理、精确布局、复杂画布编辑 |
| 撤销粒度 | 需要 `Ctrl/Cmd+Z` 逐步撤销 | 一键撤销全部或逐条选择           |

### 示例

- "在选中节点旁边创建一个笔记，内容是它的摘要"
- "把所有 PDF 节点归入一个叫'参考文献'的 Frame"
- "将画布上的节点按主题重新分组"

---

## 多轮对话

每个聊天线程（Thread）保持完整的对话历史，AI 能记住之前的问答。

- 对话历史持久化存储在本地数据库（`langgraph-checkpoints.sqlite`）
- 重启应用后，历史对话仍然保留
- 不同的研究主题建议使用不同的线程，保持上下文清晰

---

## 从对话到画布

对话中 AI 生成的节点会带有 `chat` 来源标记，自动布局时会与同一线程的其他节点聚集在一起（见 [05 · 自动布局](./05-auto-layout.md)）。

你也可以将聊天消息中的内容**直接拖到画布上**，创建为 Note 节点。

---

## 注意事项

- AI 回复的质量取决于 LLM 提供商的模型能力，请确保 `.env` 中配置了有效的 API Key
- 复杂指令（如"整理整个画布"）可能需要几秒到几十秒
- Chat 和 Deep Research 模式下的画布操作均可通过 `Ctrl/Cmd+Z` 撤销；Agent 模式提供专用的变更清单来管理撤销
