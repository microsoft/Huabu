# 04 · 节点详解

Huabu 共有 **9 种节点类型**，每种承载不同的内容、提供不同的交互方式。本章先讲所有节点共享的能力，再分别介绍每一种。

---

## 节点通用能力

### 1) 展开（右侧大屏 / 编辑面板）

- **内容类节点**（Note / Web / PDF / Image / Video）：双击节点会在右侧打开大屏预览/编辑面板；也可点节点工具栏的"打开大屏"按钮
- **Text / Question**：双击进入**原地编辑**，不进入右侧面板
- **Frame / Annotation**：无大屏

### 2) 单选时的节点工具栏

选中**单个**节点时，节点上方会出现一个浮动工具栏。不同节点工具栏不同，但遵循同一原则：

| 节点          | 工具栏                                                     |
| ------------- | ---------------------------------------------------------- |
| Note          | 打开大屏、复制内容                                         |
| Web           | 打开原网页（新标签页）、打开大屏                           |
| PDF           | 打开大屏、下载、删除封面（已设置封面时）                   |
| Image / Video | 打开大屏                                                   |
| Text          | 字体 / 字号、加粗 / 斜体 / 下划线 / 删除线、文字色、背景色 |
| Question      | 编辑、运行 / 停止、查看回复                                |
| Frame         | 布局子节点、解散分组                                       |
| Annotation    | （由父节点工具栏提供，见下文）                             |

### 3) 多选浮动工具栏

多选后画布出现工具栏，可对齐（左/中/右、上/中/下）、分散重叠节点、按 `Ctrl/Cmd+G` 聚合到新 Frame。

### 4) 锁定（固定节点 / 防止误操作）

在左侧 Layers 面板每个节点行右侧悬停会出现锁定按钮。锁定**适用于所有节点类型**。

锁定后的通用效果：

- **不可拖动 / 调整尺寸**
- **自动布局视为固定点**：不会被重新定位或调整尺寸
- **仍可删除、仍可编辑内容**（通过 Layers 面板或右侧大屏）

锁定 Frame 的额外效果：

- 子节点不可单独拖动（仍可选中）
- 子节点也被自动布局视为固定
- 不会接收新的子节点，也不会释放已有子节点
- 不会自动收缩/扩展以包裹子节点
- 仍可解散

## Note（便签） 📋

> 笔记、想法、摘要、AI 生成的文字内容

| 特性       | 说明                                                                         |
| ---------- | ---------------------------------------------------------------------------- |
| 编辑方式   | 双击展开右侧编辑面板（基于 BlockNote）                                       |
| 格式支持   | Markdown 语法、标题、列表、加粗、代码块等富文本块                            |
| 拆分到画布 | 在编辑面板里把一个块用左侧把手**拖到画布**，可快速把长笔记拆成多个 Note 节点 |
| 入库       | Note 内容会自动入库到 Sources，让 AI 后续可检索                              |

## Text（文本块） T

> 标题、标签、画布上的简短说明

| 特性     | 说明                                                  |
| -------- | ----------------------------------------------------- |
| 编辑方式 | 双击直接原地编辑                                      |
| 格式支持 | 纯文本，可调字号、加粗 / 斜体 / 下划线 / 删除线、颜色 |
| 自适应   | 节点尺寸根据文字内容自动调整                          |

## Web（网页） 🌐

> 收藏网页、在线文章、参考链接

| 特性       | 说明                                        |
| ---------- | ------------------------------------------- |
| 创建方式   | 粘贴 URL、链接弹窗、Sources 拖入            |
| 内容入库   | 后台抓取页面正文并入库到 Sources，AI 可检索 |
| 节点工具栏 | 在浏览器中打开原网页、打开大屏              |

---

## PDF 📖

> 论文、报告、说明文档

| 特性       | 说明                                                                                                                             |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------- |
| 创建方式   | 上传本地 PDF、粘贴 PDF 文件、粘贴 PDF URL                                                                                        |
| 渲染       | 默认显示首页 / 多页缩略图，节点工具栏可下载                                                                                      |
| 大屏选区   | 在 PDF 大屏中进入"选区"模式：框选任意区域后会出现浮动面板，支持把**选区文字拖到画布生成 Note**、把**选区截图拖到画布生成 Image** |
| 设置封面   | 选区截图可一键设为该 PDF 节点的封面（节点会显示封面图）；已设置封面时可在节点工具栏中删除封面以恢复多页预览                      |
| 发送到对话 | 选区截图 / 文本可一键作为待发送附件发送给 Chat                                                                                   |
| 入库       | PDF 文本会自动提取并入库，供 AI 检索                                                                                             |

## Image（图片） 🖼️

> 截图、图表、设计稿、参考图

| 特性     | 说明                                       |
| -------- | ------------------------------------------ |
| 支持格式 | PNG / JPG / GIF / WebP / SVG               |
| 创建方式 | 上传、粘贴（截图）、粘贴 URL、PDF 选区截图 |
| 自适应   | 节点尺寸自动按图片宽高比调整               |

> 💡 直接 `Ctrl/Cmd+V` 可粘贴剪贴板中的截图，自动创建 Image 节点。

| 创建方式 | 上传本地视频、粘贴文件、粘贴视频 URL      |

## Frame（分组框） 🗂️

> 按主题或阶段对节点分组

| 特性       | 说明                                                                               |
| ---------- | ---------------------------------------------------------------------------------- |
| 子节点     | 拖入 Frame 区域的节点自动成为子节点，随 Frame 一起移动                             |
| 聚合创建   | 多选节点后按 `Ctrl/Cmd+G` 一键创建 Frame 并纳入                                    |
| 嵌套       | 支持 Frame 嵌套                                                                    |
| 自动调整   | 启用自动布局时，Frame 自动收缩 / 扩展以包裹子节点                                  |
| 布局子节点 | Frame 工具栏的"布局"按钮只对该 Frame 内部布局，不影响画布其他部分                  |
| 锁定       | 锁定后不再接收 / 释放子节点、不再自动调整尺寸；子节点也被视为固定（详见上文"锁定") |
| 节点工具栏 | 布局子节点、解散 Frame                                                             |

## Question（问题节点）

> 把一个问题直接写在画布上 —— AI 会自动回答到旁边

Question 节点是**画布原生的 Ask 入口**，不需要打开 Chat 面板。

工作流程：

1. 在画布上插入一个 Question 节点（或通过对应的工具按钮 / 快捷创建）
2. 双击进入编辑，写下你的问题；离开编辑或点"运行"按钮，节点状态变为 `pending`
3. 系统把问题 + **它在画布上的空间上下文**（周围有什么节点、所属 Frame、关联连线）作为 prompt 发给 AI
4. 节点显示运行状态（等待 / 思考中 / 完成 / 失败）
5. 回答以新节点形式出现在 Question 旁边，并用连线指回 Question
6. 可在节点工具栏查看完整对话回放，或编辑问题重新运行

> 💡 Question 节点尤其适合"在某个区域提一个聚焦的小问题"，因为 AI 拿到的不是整张画布，而是**问题节点附近的语义邻域**。

## Annotation（手绘批注）

> 用画笔在画布上做高亮、圈注、签批

Annotation 节点是 SVG 路径，记录你画下的轨迹。它通常**附着在另一个节点之上**作为标注。

| 特性     | 说明                                                         |
| -------- | ------------------------------------------------------------ |
| 创建方式 | 进入批注模式后在画布上手绘                                   |
| 颜色     | 创建时选择颜色，节点本身不可调整大小但会随父节点缩放         |
| 识别意图 | 选中批注后可让 AI 解释你画的标记代表什么（接到 Intent 系统） |
| 删除     | `Delete` / `Backspace`                                       |
