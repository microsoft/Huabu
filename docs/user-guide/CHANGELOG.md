# 功能更新日志

每次重要功能变更都会记录在此文件中，按时间倒序排列。

---

## 2026-03-13 · 画布导入导出移至列表页 & 404 提示

**变更内容**

- **导入/导出移至画布列表页**：导入和导出功能从画布编辑器的工作区菜单移至首页画布列表页，操作更直观。

**注意事项**

- 画布编辑器内的工作区菜单不再包含导入选项。
- 导入的画布始终创建为新画布，不会覆盖现有数据。

---

## 2026-03-13 · 多画布与路由导航

**变更内容**

支持在工作区中创建和管理多个画布，并通过 URL 路由在不同画布之间导航。

- 新增**画布列表页**（`/`）：展示工作区内所有画布，可快速创建新画布或点击进入已有画布。
- 画布页面通过 URL 路由访问：`/canvas/:canvasId`。
- 切换画布时自动保存当前画布、清理撤销历史和剪贴板。

**注意事项**

- 默认画布 (`default-canvas`) 保持不变，升级后可直接通过 `/canvas/default-canvas` 访问。

---

## 2026-03-13 · 工作区文件夹选择器

**变更内容**

工作区路径由用户通过系统原生文件夹选择器设置。

- **首次启动引导**：第一次打开应用时显示欢迎页面，引导用户选择工作区文件夹（或手动输入路径）。
- **原生文件夹选择器**：点击"Select Folder"按钮会弹出操作系统原生的文件夹选择对话框（Windows/macOS/Linux）。
- **路径持久化**：选定的路径存入浏览器 `localStorage`，下次打开自动恢复，无需重新选择。
- **随时切换**：在 Settings（齿轮图标）中可随时更换工作区文件夹，切换后立即生效。
- 新增后端 API：`POST /api/workspace/pick-folder` — 打开原生文件夹选择对话框。

**⚠️ 注意事项**

- 升级后首次打开需要重新选择工作区文件夹。

---

## 2026-03-12 · 后端存储迁移至文件系统

**变更内容**

画布和知识库的持久化方式从 SQLite 数据库迁移至基于文件的存储。数据以 JSON / Markdown 格式直接保存在工作区目录中，便于浏览、备份和版本管理。

- **画布** → `<workspace>/canvas/<canvasId>.json`（原子写入）
- **知识来源** → `<workspace>/sources/<Title>.md`（Markdown + YAML frontmatter，可用任意编辑器查看）
- **附件** → `<workspace>/artifacts/artifact-<uuid>.<ext>`（原始二进制文件）

详细结构及配置方式见 [08 · 数据存储](./08-data-storage.md)。

**⚠️ 注意事项**

- **不会自动迁移**：升级后旧版 SQLite 中的画布和知识库数据不会自动转移到新存储。
- **推荐迁移步骤**：
  1. 在旧版本中使用导出功能将画布导出为 `.sediment.json` 文件
  2. 更新到新版本并重新启动服务
  3. 使用导入功能将导出文件导入新存储
- 导出/导入会完整保留节点、连线、知识来源和附件，可放心操作。
