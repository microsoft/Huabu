# 08 · 快捷键参考

> `Ctrl` 在 Windows / Linux 上，`Cmd (⌘)` 在 macOS 上，下文统一写作 `Ctrl/Cmd`。

---

## 编辑

| 快捷键                 | 操作                         |
| ---------------------- | ---------------------------- |
| `Ctrl/Cmd+Z`           | 撤销                         |
| `Ctrl/Cmd+Shift+Z`     | 重做                         |
| `Ctrl/Cmd+C`           | 复制选中节点                 |
| `Ctrl/Cmd+V`           | 粘贴节点 / 文件 / URL / 文本 |
| `Delete` / `Backspace` | 删除选中节点或连线           |

---

## 布局

| 快捷键                         | 操作                                   |
| ------------------------------ | -------------------------------------- |
| `Ctrl/Cmd+=` / `Ctrl/Cmd++`    | 放大画布                               |
| `Ctrl/Cmd+-`                   | 缩小画布                               |
| `Space`（按住）                | 临时切换到抓手（平移）                 |
| `Alt`（拖拽 / 调整大小时按住） | 临时关闭节点拖拽与缩放的智能对齐与吸附 |

> 自动布局开关没有快捷键，请打开 Header 右上角的设置弹窗（齿轮图标）→ Canvas 区块切换 **Auto Layout**。

---

## 层级与分组

| 快捷键       | 操作                             |
| ------------ | -------------------------------- |
| `[` / `【`   | 将选中节点置底（Send to Back）   |
| `]` / `】`   | 将选中节点置顶（Bring to Front） |
| `Ctrl/Cmd+G` | 将选中节点群组到一个新 Frame     |

---

## AI

| 快捷键       | 操作                   |
| ------------ | ---------------------- |
| `Ctrl/Cmd+I` | 触发意图识别（Intent） |

---

## 帮助 / 弹窗

| 快捷键           | 操作                               |
| ---------------- | ---------------------------------- |
| `?`              | 打开快捷键帮助弹窗                 |
| `Esc`            | 取消当前工具 / 关闭弹窗 / 退出大屏 |
| `Ctrl/Cmd+Enter` | 在链接输入弹窗中确认提交           |

---

## 粘贴行为说明

`Ctrl/Cmd+V` 的具体行为取决于剪贴板内容：

| 剪贴板内容               | 粘贴结果                                                  |
| ------------------------ | --------------------------------------------------------- |
| 已复制的画布节点（内部） | 在鼠标位置粘贴节点副本                                    |
| 图片文件                 | 创建 Image 节点并上传                                     |
| PDF 文件                 | 创建 PDF 节点并上传                                       |
| 视频文件                 | 创建 Video 节点并上传                                     |
| 一行或多行 URL           | 自动识别类型（图片 / PDF / 网页 / YouTube），逐行创建节点 |
| 普通文本                 | 创建 Note 节点，内容为粘贴的文字                          |
