# 08 · 快捷键参考

> `Ctrl` 在 Windows / Linux 上，`Cmd (⌘)` 在 macOS 上，下文统一写作 `Ctrl/Cmd`。

---

## 编辑

| 快捷键                 | 操作                         |
| ---------------------- | ---------------------------- |
| `Ctrl/Cmd+Z`           | 撤销                         |
| `Ctrl/Cmd+Shift+Z`     | 重做                         |
| `Ctrl/Cmd+C`           | 复制选中节点                 |
| `Ctrl/Cmd+V`           | 粘贴节点 / 文件 / URL / 文本 |
| `Delete` / `Backspace` | 删除选中节点或连线           |

---

## 布局

| 快捷键                         | 操作                                                        |
| ------------------------------ | ----------------------------------------------------------- |
| `Ctrl/Cmd+=` / `Ctrl/Cmd++`    | 放大画布                                                    |
| `Ctrl/Cmd+-`                   | 缩小画布                                                    |
| `Space`（按住）                | 临时切换到抓手（平移）                                      |
| `Space`（拖拽节点时按住）      | 暂停自动 reparent：节点不会进入或离开任何 frame，仅移动位置 |
| `Alt`（拖拽 / 调整大小时按住） | 临时关闭节点拖拽与缩放的智能对齐与吸附                      |

> 拖拽节点时 `Space` 与 "切换抓手" 的两种语义按上下文区分：正在拖一个节点时优先解释为 "禁用 reparent"，没有拖拽时仍是切换抓手。

---

## 层级与分组

| 快捷键       | 操作                             |
| ------------ | -------------------------------- |
| `[` / `【`   | 将选中节点置底（Send to Back）   |
| `]` / `】`   | 将选中节点置顶（Bring to Front） |
| `Ctrl/Cmd+G` | 将选中节点群组到一个新 Frame     |

## AI

| ------------ | ---------------------- |
| `Ctrl/Cmd+I` | 触发意图识别（Intent） |

## 搜索

`Ctrl/Cmd+F` 会根据焦点位置自动决定要搜什么：

- 焦点在画布上 → 打开顶部居中的**画布搜索浮层**，结果按字段分为 _Meta_（标题 / 摘要 / 关键词）与 _Content_（正文）两段流式返回。
- 焦点在右侧展开的节点预览中 → 在预览正文上方弹出**就地查找条**，仅高亮当前预览内的命中。

| 快捷键        | 操作                                                 |
| ------------- | ---------------------------------------------------- |
| `Ctrl/Cmd+F`  | 打开搜索（画布浮层 或 预览内查找条）                 |
| `↑` / `↓`     | 在画布浮层中切换上一/下一条结果                      |
| `Enter`       | 跳转到当前结果（画布浮层），或前往下一条匹配（预览） |
| `Shift+Enter` | 前往上一条匹配（预览内查找）                         |
| `Esc`         | 关闭搜索                                             |

> 搜索后台采用 **NDJSON 流式协议**：第一批 Meta 命中通常在百毫秒级到达，正文阶段会边读边推。每次按键都会取消上一次未完成的请求，无需等待。

## 粘贴行为说明

`Ctrl/Cmd+V` 的具体行为取决于剪贴板内容：

| 剪贴板内容               | 粘贴结果                                                  |
| ------------------------ | --------------------------------------------------------- |
| 已复制的画布节点（内部） | 在鼠标位置粘贴节点副本                                    |
| 图片文件                 | 创建 Image 节点并上传                                     |
| PDF 文件                 | 创建 PDF 节点并上传                                       |
| 视频文件                 | 创建 Video 节点并上传                                     |
| 一行或多行 URL           | 自动识别类型（图片 / PDF / 网页 / YouTube），逐行创建节点 |
| 普通文本                 | 创建 Note 节点，内容为粘贴的文字                          |

## 拖拽语义（Note 块 → 画布 / Note）

把 Note 编辑器里的某个块（段落 / 列表 / 标题 / 代码块 …）拖到画布或另一个 Note 时，修饰键决定是"移动"还是"复制"：

| 操作                  | 行为                                                  |
| --------------------- | ----------------------------------------------------- |
| **直接拖拽**          | **移动**：源 Note 删掉该块，目标位置新建/插入相同内容 |
| **`Ctrl/Cmd` + 拖拽** | **复制**：源 Note 保留原文，目标位置新建/插入相同内容 |

落点决定内容如何放置：

| 落点                                       | 行为                                                  |
| ------------------------------------------ | ----------------------------------------------------- |
| 画布空白处                                 | 新建一个 Note 节点                                    |
| 画布上的 **Note 瓦片**                     | 追加到该 Note 末尾（按 block 间隔），瓦片高亮蓝环反馈 |
| 右侧**展开编辑面板**里的 Note              | 在光标所在 block 之后**精确插入**                     |
| 锁定的 Note                                | 不接收 → 退化为在该位置新建节点                       |
| 把自己的某块拖回**自己**（瓦片或展开面板） | 转给 Crepe 的 in-editor block 重排，不进入本流程      |

> 鼠标光标会随修饰键切换：复制时显示带 `+` 号的箭头，移动时显示普通箭头。来源不可回写的拖拽（Chat 消息卡片、Web / Image 卡片、外部文件 / URL）始终走"复制"，按不按 `Ctrl/Cmd` 都一样。
