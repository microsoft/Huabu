# Huabu 用户指南

Huabu 是一个面向人机协作的画布框架。你的想法、笔记、文档、问题、AI 产出都以**持久化节点**的形式被放在同一块二维画布上 —— 人和 AI 共享同一个工作空间，彼此都能读、也都能写。

本仓库 `sediment` 是 Huabu 的参考实现。
