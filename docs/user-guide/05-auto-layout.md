# 05 · 自动布局

Sediment 内置了基于力导向算法的自动布局系统，能根据节点之间的**显式连线**和**隐式语义关系**自动排列节点位置。

---

## 三种布局操作

| 操作                 | 范围                    | 触发方式                             | 效果                                     |
| -------------------- | ----------------------- | ------------------------------------ | ---------------------------------------- |
| **布局全部**         | 画布所有节点            | `Ctrl/Cmd+Shift+L` 或工具栏按钮      | 重新排列所有节点；视口自动适应结果       |
| **布局 Frame**       | 某个 Frame 的所有子节点 | Frame 工具栏的布局按钮               | 仅重新排列该 Frame 内的节点              |
| **自动放置**（增量） | 单个新建节点            | 开启自动布局后，新节点创建时自动触发 | 将新节点插入到关联节点附近，其余节点不动 |

所有布局操作均可用 `Ctrl/Cmd+Z` 撤销。

---

## 自动布局开关

工具栏上有一个全局开关（✨ 图标，快捷键 `Ctrl/Cmd+Shift+A`）控制**增量自动放置**是否启用：

- **开启时**（按钮高亮）：每个新创建的节点自动被放置到最合适的位置
- **关闭时**（默认）：新节点出现在画布中央，不自动移动

开启自动布局时的附加效果：

- Frame 会**自动调整大小**，始终紧密包裹其所有子节点
- 拖动节点时，可以看到目标 Frame 的**预览边框**，显示松手后 Frame 将如何调整

---

## 隐式语义边

布局引擎不仅使用你手动连的线，还会识别节点间的**隐式关系**，把相关节点拉近：

| 关系类型     | 权重  | 说明                                         |
| ------------ | ----- | -------------------------------------------- |
| 用户连线     | `1.0` | 手动绘制的画布连线                           |
| 研究引用     | `0.6` | 合成节点 → 它引用的来源节点                  |
| 知识来源     | `0.4` | 节点 → 其所属的知识库来源节点                |
| 同一研究线程 | `0.3` | 同一次 AI 研究会话产生的所有节点（两两连接） |
| 同一对话线程 | `0.3` | 从同一聊天线程拖出的节点（两两连接）         |
| 同一 Frame   | `0.2` | 同一 Frame 内的兄弟节点（两两连接）          |

**规则**：两节点间有多种关系时，只取权重最高的一条，不累加。

这意味着：即使你没有手动连线，AI 生成的相关节点也会在布局时自然聚集在一起。

---

## 布局算法

底层使用两个求解器，根据操作类型选择：

| 场景                  | 算法                               | 特点                                         |
| --------------------- | ---------------------------------- | -------------------------------------------- |
| 布局全部 / 布局 Frame | **WebCola**（stress majorization） | 从当前位置出发，平滑迭代收敛，保留空间记忆   |
| 自动放置新节点        | **fCoSE** + 固定约束               | 现有节点位置完全固定，只计算新节点的最优落点 |

两个算法都原生支持 Frame 复合节点和断连图（多个孤立节点组）。

---

## 使用建议

- **刚开始整理**：先随意摆放节点和建立连线，随时按 `Ctrl+Shift+L` 一键整理
- **研究过程中**：开启自动布局，让 AI 生成的节点自动聚集到关联内容旁边
- **精细调整**：手动拖动到满意位置后，关闭自动布局防止被自动改动
- **Frame 内整理**：对单个 Frame 独立布局，不影响画布其他部分
