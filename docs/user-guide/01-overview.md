# 01 · 产品概览

## Sediment 是什么？

<!-- TODO: update -->

Sediment 是一个**自由且灵活的思考空间**。
你看到，想到的所有内容都可以在上面随意的排列组合，形成一个属于你自己的知识地图。它把你的想法、笔记、资料、灵感都承载在一个无限的画布上，让你在整理思路的同时获得实时辅助。

主要特点：

- **多类型节点**：在同一画布混合摆放文本、网页、PDF、图片、视频等内容
- **AI 对话侧边栏**：与 Agent 对话，Agent 可以直接在画布上创建和修改节点
- **意图识别**：按 `Ctrl/Cmd+I` 让 AI 根据当前画布状态推测你的意图并提供操作建议
- **自动布局**：基于语义关系的力导向布局，自动整理节点位置
- **知识库**：将画布内容持久化为可检索的知识来源

## 核心概念

### 画布（Canvas）

画布是 Sediment 的主工作区，是一个支持无限滚动与缩放的二维空间。你可以在其中自由放置、移动、连线各类节点。

### 节点（Node）

节点是画布的基本单元，每个节点承载一种类型的内容：

| 类型  | 图标 | 描述                              |
| ----- | ---- | --------------------------------- |
| Note  | 📝   | 可编辑的富文本便签，支持 Markdown |
| Text  | T    | 纯文本块，适合标注说明            |
| Web   | 🌐   | 嵌入式网页预览                    |
| PDF   | 📄   | PDF 文档阅读器                    |
| Video | 🎬   | 视频播放器                        |
| Image | 🖼️   | 图片展示                          |
| Frame | 🗂️   | 容器，用于对其他节点进行分组      |

### 连线（Edge）

节点之间可以用连线表示关系。AI Agent 在执行任务时也会自动建立连线，使关联内容在视觉上更清晰。

### Frame（分组框）

Frame 是一种特殊节点，可以包含多个子节点，形成视觉上的分组。Frame 支持锁定、独立布局，以及拖入拖出子节点。

### 意图（Intent）

按 `Ctrl/Cmd+I` 触发意图识别：AI 会分析当前画布状态与历史操作，推荐若干可执行的下一步操作（如「为选中节点生成摘要」、「关联相关来源」等），点击即可一键执行。
