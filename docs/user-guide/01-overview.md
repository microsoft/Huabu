# 01 · 产品概览

## Huabu 是什么

Huabu 是一个**基于画布的人机协作框架**。它提供一块共享的二维工作空间，让想法、笔记、文档、问题、AI 产出都作为**持久化节点**被组织起来。AI 不再是独立于工作之外的对话窗口 —— 它和你处在同一块画布上，能看到你看到的，也能在你身边动手。

本仓库 `sediment` 是 Huabu 的参考实现。

---

## 两条核心原则

### 1) Externalize Thinking — 把思考外化

画布把**正在成形的思路**显性化：你可以把碎片化的笔记、问题、参考资料铺开来，离开工作记忆去整理、修改、回看。画布承载的不只是内容，还有**结构**：节点的空间排列本身就在表达关系、优先级、不确定性，以及正在浮现的主题聚类。

### 2) Share Cognitive Space — 共享认知空间

因为 AI 与你工作在同一块画布上，它能看到的是**整体语境**，而不只是最后一条指令。这让它可以：

- 帮你**整理素材**（分类、对齐、归入 Frame）
- 在多个节点间**做综合**（写综述、对比、抽提观点）
- 指出**还没解决的问题**
- 把零散内容**推进成更结构化、更可执行的产出**

画布是共享记忆，人和 AI 都从中读取，也都向其中写入。

## 三个核心对象

```
Workspace（你选的本地文件夹）
   ├── Canvas（一块画布）
   │      └── Node / Edge（节点与连线）
   └── Sources（被持久化、可被 AI 检索的来源）
```

| 对象          | 含义                                                                                                                                     |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| **Workspace** | 一个本地文件夹，所有数据都落在这里。一台机器可以记住多个最近工作区，随时切换。详见 [02 · 工作区与画布](./02-workspace-and-canvases.md)。 |
| **Canvas**    | 一张无限大小的二维画布，是主要的工作空间。一个工作区可以有多张画布。详见 [03 · 画布基础](./03-canvas-basics.md)。                        |
| **Node**      | 画布上的基本单元，每种节点承载一种内容类型（笔记、网页、PDF、图片、视频、问题、批注、Frame 等）。详见 [04 · 节点详解](./04-nodes.md)。   |
| **Source**    | 可被 AI 检索的持久化来源，存为带有 frontmatter 的 Markdown。详见 [05 · Sources 与知识库](./05-sources-and-knowledge.md)。                |

## 与 AI 协作的两种姿态

| 模式        | 适用场景                                                        |
| ----------- | --------------------------------------------------------------- |
| **Ask**     | 自由对话、提问、解释、轻量整理。AI 主要"读"画布，按需调用工具。 |
| **Operate** | 描述你想要的画布变更，AI 解析为一组可预览/可整体撤销的操作。    |

此外还有两种**画布原生**的协作入口：

- **Question 节点** — 在画布上写下一个问题，节点会自动调用 AI 把回答接到画布旁边
- **Intent 系统**（`Ctrl/Cmd+I`） — 让 AI 基于当前画布状态推荐"接下来做什么"，一键执行

详见 [06 · 人机协作](./06-ai-collaboration.md) 与 [07 · 意图与自动布局](./07-intent-and-auto-layout.md)。

## 第一次使用

1. 启动应用，在 [02 · 工作区与画布](./02-workspace-and-canvases.md) 里**选一个本地文件夹**作为工作区
2. 在画布主页**新建一张画布**
3. 在 [09 · 设置与 LLM](./09-settings-and-llm.md) 里配置模型提供商和 API Key（也支持 GitHub Copilot OAuth 登录）
4. 开始往画布上放内容，按 `Ctrl/Cmd+I` 让 AI 给你"接下来做什么"的建议
