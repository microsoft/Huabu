# 触摸屏画布交互 · 真机测试清单

Status: Manual test plan for the touch/pen canvas work on branch `sketch`. Behaviour reference: `docs/architecture/canvas-input-interactions.md`.
Last updated: 2026-07-19

> 用法:在 iPad / 触摸屏设备上逐条做"动作",核对"预期"。每格是一个具体手势 → 应发生的结果。
> 建议分别在 **笔 + 手指**、**纯手指**、**鼠标** 三种情况各过一遍。

## 0. 前置:输入模式

- [ ] 设置里能看到输入偏好:Auto / 鼠标 / 笔 / 手指。
- [ ] **Auto**:一块新画布,先用手指操作 → 解析为 **Finger**;用笔点一次后 → 永久解析为 **Pen**(刷新后仍是 Pen)。
- [ ] 显式选 **笔** / **手指** / **鼠标** 后,不被观察结果改写。
- [ ] **鼠标模式**:手指/笔在画布上完全无效(不画、不选、不移、不平移)。

---

## 1. Pen 模式(手里有笔 + 另一只手手指)

### 画 / 擦(笔)

- [ ] 选 **Sketch** 工具,**笔**在空白处拖 → 画出墨迹(带压感)。
- [ ] Sketch 切到**橡皮**,**笔**划过一条笔画 → 只擦掉这条笔画。
- [ ] **手指**在 Sketch 工具下划过笔画 → **不**画、**不**擦(笔才画,手指管导航/选择)。

### 选中 / 移动(手指)

- [ ] **手指轻点**一个节点 → 选中它(出现选择框 + 浮动工具栏)。
- [ ] **手指轻点**空白 → 取消选择。
- [ ] 节点**已选中**,**手指按住它拖** → 移动该节点(**Select 工具**下)。
- [ ] 切到 **Sketch 工具**,节点已选中,**手指按住它拖** → 照样移动节点;同时**笔仍能画**。
- [ ] 节点**未选中**,**手指按住它拖** → **平移画布**(不移动节点)。先轻点选中、再拖才移动。
- [ ] 多选多个节点后,**手指拖其中任一个** → 整组一起移动。
- [ ] 移动节点后 **撤销一次** → 节点回到原位(单条撤销,不需按多次)。

### 移动节点(笔,仅 Select 工具)

- [ ] **Select 工具**下,**笔轻点**节点 → 选中。
- [ ] **Select 工具**下,**笔拖**已选中节点 → 移动它。
- [ ] (对照)**Sketch 工具**下笔是在画,**不**移动节点——要用笔移动需先切 Select。

### 导航(手指)

- [ ] **手指拖**空白 → 平移画布。
- [ ] **双指** → 缩放 + 平移,平滑跟手。
- [ ] 正在**手指拖动节点**时,**第二根手指**落下 → 拖动不被打断(不缩放、不另起平移)。
- [ ] 正在**双指缩放**时加**第三指** → 缩放不冻结;松回两指也不跳变。

---

## 2. Finger 模式(纯手指,无笔)

### 默认与工具

- [ ] 进入一块**已有内容**的画布,默认工具是 **Select**(不是 Sketch/橡皮),手一搭上去不会误画。
- [ ] 触摸底部工具栏显示 **Select** 和 **Lasso**(下拉菜单里选中项**没有多余对勾**)。
- [ ] 选 Note/Text/Frame 放置一个后 → 自动回到 **Select**(**不**跳回 Sketch)。

### 选中 / 移动

- [ ] **Select** 工具:**轻点**节点 → 选中;**轻点**空白 → 取消选择。
- [ ] **Select** 工具:**按住已选中**节点拖 → 移动;**按住未选中**节点拖 → 平移(先选后拖)。
- [ ] 多选后拖其中一个 → 整组移动;移动后撤销一次回退。

### 画 / 擦

- [ ] 选 **Sketch**,**手指**画墨迹;切**橡皮**,手指划过笔画 → 擦除。
- [ ] **Sketch/橡皮** 工具下**轻点**一个节点 → **不**选中(纯手指下要选须切 Select)。

### 导航

- [ ] **单指拖**空白 → 平移;**双指** → 缩放 + 平移。

---

## 3. 创建 / 工具(触摸)

- [ ] **Note / Text / Question**:点工具 → 轻点空白 → 放置一个节点 → 回到 Select。
- [ ] **Frame**:选 Frame → 拖出矩形 → 创建 frame。**拖拽过程中画布保持静止(不漂移)**。
- [ ] **Lasso**:拖出套索 → 框选圈住的节点。**拖拽过程中画布保持静止**。
- [ ] **新建空画布**首次进入:笔/手指 → 自动 arm **Sketch**(可直接画一笔);鼠标 → arm **Note**。画一笔 / 放置后回落 **Select**。

---

## 4. 误触 / 浏览器默认行为

- [ ] 画 / 平移 / 套索 / 拖动节点时,手势**划过节点或面板文字** → **不**选中文字、**不**弹"拷贝 / 共享"菜单。
- [ ] 进入 **note 编辑**(双击或进入编辑)→ note 内文字**能正常选中**。
- [ ] **长按**画布空白 → **不**弹系统右键 / callout;长按**链接 / 输入框** → 保留原生菜单。
- [ ] **双击 / 双指**不触发浏览器页面缩放,不触发下拉刷新。
- [ ] 手掌 / 多余手指静置在画布上 → 不误画、不误擦、不误移(尽力,受硬件掌拒影响)。

---

## 5. 缩放 / 平移健壮性

- [ ] **双指缩放不失灵**(此前 React Flow 内建 pinch 与自定义 pinch 冲突已修)。
- [ ] 缩放围绕**双指中点**,不跳变;放大到边界有合理上限/下限。
- [ ] 单指平移 → 松手不残留;平移中不误选、不误触发工具。

---

## 6. Mouse 模式回归(桌面)

- [ ] 单击选中、拖动移动、**拖空白框选**、中键 / 滚轮平移、滚轮缩放,均正常。
- [ ] 桌面工具栏 **Select / Pan / Lasso** 齐全,快捷键 **S / P / L** 生效;下拉选中项无多余对勾。
- [ ] 鼠标**仍能选中节点文字**复制(触摸端禁选不影响桌面)。
- [ ] 创建工具激活时中键仍可平移。

---

## 7. 混合设备(可选,Surface / 触屏笔记本)

- [ ] 同一设备上:手用**鼠标** → 桌面式工具栏与交互;换成**手指** → 立即变触摸式;二者互不串味。
- [ ] 用鼠标时可选中节点文字;切手指后同一处手势不再选中文字。
