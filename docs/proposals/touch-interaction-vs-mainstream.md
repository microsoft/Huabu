# 触摸屏画布交互：与主流两派的对照

Status: Informational — reflects shipped behaviour after the "Select-as-touch-default" and "pen-mode finger tap-select" changes (branch `sketch`). Authoritative behaviour lives in `docs/architecture/canvas-input-interactions.md`; this note is rationale/context only.
Last updated: 2026-07-19

## 背景：主流分两派

触摸屏上的"画笔 + 选择"交互，业界大致分成两派，各自都主流，只是产品定位不同。

| 派别                    | 代表                                      | 画笔工具下轻点物体 | 怎么选                       |
| ----------------------- | ----------------------------------------- | ------------------ | ---------------------------- |
| 白板 / 图表派           | Figma、FigJam、Excalidraw、Miro           | 不选（画个点）     | 切到 Select 工具             |
| 笔记 / 绘画派（笔优先） | GoodNotes、Notability、Procreate、OneNote | 笔画；手指选 / 移  | 手指这条独立通道，不用切工具 |

关键区分点：**"画笔工具下手指也能选"只有在"有笔"时才无歧义**——笔画画、手指专门选 / 导航。纯手指（无笔）时手指不能同时既画又选，所以笔记派在纯手指下**也**退回"切 Select 工具"。

## Sediment 现在站在哪

我们按**输入是否有歧义**分层，等于同时借用了两派：

- **Pen 模式**（有笔）→ 走笔记派：笔画、手指选 / 导航，不用切工具。
- **Finger 模式**（纯手指）→ 走白板派：要画就画、要选切 Select。
- **Mouse 模式** → 桌面习惯，保持不变。

## 逐项对照

"√ 相同 / ✗ 不同 / ≈ 部分相同"是相对该派而言。

| 维度                          | 白板派                 | 笔记派（笔优先）         | Sediment 现状                                                                                 | 与白板派 | 与笔记派    |
| ----------------------------- | ---------------------- | ------------------------ | --------------------------------------------------------------------------------------------- | -------- | ----------- |
| 触摸默认工具                  | Select（安全，不误触） | 画笔（拿起就画）         | **Select**（一次性：新空画布首帧 arm Sketch，用完回落 Select）                                | √        | ≈           |
| 画笔是否粘性                  | 是，主动进入、留着     | 是                       | **是**（Sketch/橡皮选了就留着，不自动回落）                                                   | √        | √           |
| 纯手指 · 画笔工具下轻点节点   | 不选（画点）           | —（纯手指也需切 Select） | **不选**（手指画；要选切 Select）                                                             | √        | √           |
| 有笔 · 画笔工具下手指轻点节点 | —（多为鼠标产品）      | **选中**（手指独立通道） | **选中**（Pen 模式手指轻点选，笔照画）                                                        | ✗        | √           |
| 有笔 · 笔轻点节点             | —                      | 画点（笔只画）           | 画点 / 操作（笔不兼职选）                                                                     | —        | √           |
| Select 工具 · 手指轻点节点    | 选中                   | 选中                     | **选中**（React Flow 原生）                                                                   | √        | √           |
| 手指拖动空白                  | 平移                   | 平移                     | **平移**（自定义指针路由驱动）                                                                | √        | √           |
| 双指                          | 缩放 + 平移            | 缩放 + 平移              | **缩放 + 平移**（自定义路由，非 React Flow 内建）                                             | √        | √           |
| 移动节点（触摸）              | 选中后拖动             | 笔移 / 手指拖已选        | Select 下拖已选节点；**Pen 下手指拖动已选节点也移动**（`node-drag` 识别器，含 Sketch 工具下） | √        | √           |
| 误触防护（静置手 / 笔）       | 强（默认 Select）      | 中（笔优先，靠掌拒识别） | **强**（默认 Select，画笔需显式进入，不自动回落）                                             | √        | ✗（更保守） |
| 框选                          | 拖空白框选             | 套索                     | **套索**（Lasso 工具；拖空白是平移不框选）                                                    | ✗        | √           |

## 一句话总结

- **和白板派相同**：Select 是安全默认、画笔粘性、纯手指下画笔工具不兼职选中、误触防护强。
- **和笔记派相同**：有笔时笔画 / 手指选的独立通道、画笔粘性、套索式框选。
- **我们独有的取舍**：用"是否有笔"在两派之间自动切换，而不是二选一；且比笔记派更强调"默认不误触"（默认永远是 Select，画笔一律显式进入）。

## 与两派的整体关系

笔记派"有笔时手指可直接拖动节点"现已实现:Pen 模式下手指按住**已选中**的节点拖动即移动它(拖空白仍平移视口),在 Select 和 Sketch 工具下都成立。移动复用了与鼠标/笔拖动完全一致的 snap、frame 重 parent、autosave、单条 undo 通道。详见 `docs/architecture/canvas-input-interactions.md` 第 3 节。
