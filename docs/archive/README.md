# Archive

Abandoned or superseded proposals that remain useful as historical context but are neither current architecture nor active implementation plans.

Shipped proposals remain at their stable paths under `docs/proposals/` with `Status: Shipped`; their implemented behavior is folded into `docs/architecture/`.

When moving a tracked proposal here, use `git mv`, retain its original status history, and add a prominent `Abandoned` or `Superseded` note linking to the replacement when one exists.

Nothing is loaded from this folder automatically — agents should treat it
as read-only history.
