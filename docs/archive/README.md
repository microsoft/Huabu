# Archive

Shipped or superseded proposals that we keep around for historical
context, but that no longer describe how the system works today.

When moving a proposal here, leave its original `Status:` header in place
and add a one-line note at the top stating the merge commit / PR and the
`architecture/*.md` doc (if any) that now owns the lasting design.

Nothing is loaded from this folder automatically — agents should treat it
as read-only history.
